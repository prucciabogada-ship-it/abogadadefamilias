# Fotografías y Recursos Visuales

Para reemplazar las imágenes genéricas con tus fotografías reales de alta resolución:

1. **Fotografía de Paula Rucci (Retrato):**
   - Nombre de archivo: `paula-rucci.jpg` (o `.png`)
   - Ubicación: `/public/images/paula-rucci.jpg`

2. **Fotografía de Firma de Contrato (Servicios):**
   - Nombre de archivo: `contract-signing.jpg` (o `.png`)
   - Ubicación: `/public/images/contract-signing.jpg`

En `src/App.tsx`, las constantes `lawyerImg` y `contractImg` están preparadas para leer estas imágenes o las URLs que prefieras.
